About this project Runtime architecture and benchmark

Relay is a working interface for a distributed agent runtime built by Sundesh Donthi. Collection tasks run concurrently; evaluation waits for their outputs. Revisions reuse compatible saved evidence and rerun the evaluation.

The public service uses embedded Python execution and SQLite. The source includes a separate worker deployment with Postgres and Redis, plus an optional C++ routing scorer. The runtime walkthrough demonstrates missing-evidence replanning.
